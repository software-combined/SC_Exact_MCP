# Code of conduct

Treat contributors and users with respect.
Use clear, constructive feedback.
Do not harass people, publish private information, or make discriminatory remarks.

Repository maintainers may remove harmful content or restrict participation.
Explain the relevant behavior when moderation affects a contributor.

For conduct concerns, ask a maintainer for a private route in a sanitized GitHub issue.
Do not include names, personal details, or evidence in that request.
For a security issue, use [private vulnerability reporting](https://github.com/software-combined/SC_Exact_MCP/security/advisories/new).
Do not include personal details or sensitive evidence in a public issue.

These principles adapt the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
